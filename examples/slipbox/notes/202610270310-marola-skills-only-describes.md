# marola-skills only describes; a skill is fixed where it lives

marola-skills lists every Claude Code skill and subagent used in marola-dev and h0ffmann's
repositories: where it lives, where it came from, what was tested. Nothing in it is loaded; each
skill stays in the repository that uses it, and is fixed there. The daily refresh uses only the
GitHub API, no model tokens.
