# mdd-risk-analysis, the first Scala

A 2017 course project at UFRJ, by three students: the maximum drawdown of a stock, how deep a
price falls from its last peak. The analysis began in R and part of it was written again in Scala
to run on Apache Spark. That is how Scala was learned, the language of the first job.
