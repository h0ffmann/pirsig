# Three forks are prior art for a second brain

Three public forks are other people's answers to the same question. basic-memory: persistent
knowledge from conversations with LLMs, kept as Markdown files on your computer, over MCP.
ai-memory: long-term memory for coding agents, so one agent can continue another's task.
onyx: a self-hosted context layer indexed from 50+ apps.

What Pirsig takes from them is in [[202610270324-second-brain-lineage]].
