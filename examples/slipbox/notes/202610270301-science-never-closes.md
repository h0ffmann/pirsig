# Science never closes

"the number of rational hypotheses that can explain any given phenomenon is infinite" (Pirsig, as
the closed-source README quotes him). So science never closes, and a method that only its owner
can open is a method nobody else can test. That is why the book puts open code first for science.

It is the root of [[202610270300-publish-the-method]].
