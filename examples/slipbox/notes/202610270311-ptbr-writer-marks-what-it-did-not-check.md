# ptbr-writer marks what it did not check

ptbr-writer rewrites technical Brazilian Portuguese for a single reading: explicit subject, one
proposition per sentence, consistent terms. It does not change thesis, authorship or conclusion,
does not look up sources, and marks with `⚠` what it did not check. marola's README carries a
"built with ptbr-writer" badge.
