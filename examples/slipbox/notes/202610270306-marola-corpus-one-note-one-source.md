# marola-corpus: one note, one source, delete what does not hold

Each note of marola-corpus is one Markdown file on one subject from one source: the title, then
the source, then short paragraphs, one fact each. Every note was written by an AI agent from its
source and none has been checked sentence by sentence by a person yet; what the source does not
confirm is deleted, not softened.
