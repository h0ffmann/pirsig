# Pin everything

A result that can move is not trusted. picasso pins toolchains in flake locks
([[202610270303-picasso-labs-pin-toolchains]]); marola-gpt pins the corpus version and the base
model's revision ([[202610270307-marola-gpt-lora-on-tucano]]); marola-corpus ships as a pinned
tarball; the profile places each work on the graph by hand "so the picture does not move between
two builds" ([[202610270316-the-works-hold-each-other]]).

For ztk: a literature note pins the commit it was read at.
