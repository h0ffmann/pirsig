# nashkell: English on disk, Latin in git

nashkell's latinizer is a git `clean`/`smudge` filter pair: you write English on your disk, and
what is committed (and what GitHub shows) has its top-level identifiers translated to Latin. A
clone without the filter sees only Latin.
